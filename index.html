Blocos

Como usar o editor

Clique em um bloco para inseri-lo no centro ou arraste-o até a posição desejada.

Use T para selecionar e mover. Segure Shift para selecionar vários blocos. Um duplo clique abre o texto do bloco.

Arraste o quadrado no canto inferior direito do bloco para mudar seu tamanho. Para os pontos de início e fim, você também pode digitar o diâmetro. Ao editar o texto, Shift+Enter insere uma quebra de linha.

Selecione uma seta e arraste as pontas para reconectar ou os pontos do meio para curvar.

Ctrl+C copia a seleção, Ctrl+V cola e Ctrl+D duplica. Ctrl+A seleciona todos os blocos. Uma seta copiada sozinha inclui os dois blocos ligados a ela.

Ctrl+Z desfaz. Ctrl+Shift+Z ou Ctrl+Y refaz. No Mac, use ⌘ no lugar de Ctrl.

Use C para conectar. Clique primeiro na origem e depois no destino.

Escolha um bloco na paleta para começar.
