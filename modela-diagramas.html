ModelaDiagramas

Editor visual para montar seus diagramas manualmente. Escolha o tipo, vá para a tela de edição e utilize as ferramentas para desenhar seus blocos e conexões.

Como montar o diagrama

  • Clique em “Novo diagrama” para abrir a tela de edição do tipo escolhido (o canvas começa vazio — você monta tudo manualmente).
  • No editor, clique ou arraste os blocos da paleta para o canvas: personagens em palito (atores), caixas de ação (casos de uso), nós de atividade, requisitos e outros.
  • Use a ferramenta Conectar para ligar os blocos com setas — no caso de uso, são as setas de associação, <<include>>, <<extend>> e generalização.
  • Arraste os blocos para posicionar, duplo clique para editar textos, e exporte o resultado em SVG, PNG ou JSON.
Blocos disponíveis

Clique em um bloco para adicionar no centro, ou arraste para o canvas.

Dica: ferramenta Selecionar: clique num bloco, arraste para mover, Excluir para remover. Conectar: clique no bloco de origem e depois no destino para criar a seta. Duplo clique em bloco ou seta edita o texto.
